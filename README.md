# スマホ一つで大学を散策できるアプリ

このアプリは山口大学のオープンキャンパスに参加される学生をターゲットにしたアプリです。<br>
オンライン・オフライン関係なく、大学の雰囲気を伝えたいと思い制作しました。<br>
<br>
スマートフォンでサイトにアクセスすると、大学の様子を再現した3Dモデルが表示されます。<br>
スマートフォンの動きに連動して画面が動き、画面を縦方向にスワイプすることで移動できます。<br>

# 実際にオープンキャンパスでポスター展示を行いました

オープンキャンパスの会場にポスターを展示し、自由に遊んでいただけるようにしました。<br>
学生や親御さんに体験していただき、良い反応を貰うことが出来ました。
